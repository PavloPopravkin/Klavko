# Klavko — інструкція для тестувальника

Klavko — безкоштовна програма для macOS (рядок меню). Вона стежить за набором тексту в будь-якій програмі та:
виправляє слова, набрані не в тій розкладці (українська ↔ англійська), виправляє очевидні помилки,
додає пропущений пробіл після розділових знаків і має гарячі клавіші для ручного перемикання й скасування.
Увесь текст обробляється локально, нічого не надсилається в мережу.

Версія для перевірки: **0.9.2**.

---

## 1. Доступ до програми

| Що | Де |
|---|---|
| Вихідний код | цей репозиторій (Swift Package) |
| Встановлена програма (запущена, у автозапуску) | `/Applications/Klavko.app` |
| Інсталяційний архів | `dist/Klavko-<версія>.zip` (після `scripts/package.sh`) (розпакувати → перенести `Klavko.app` в `/Applications` → відкрити) |
| Опис для користувача | `README.md` |

Команди (з кореня репозиторію):

```bash
swift test                    # 40 модульних тестів логіки (словники, ранжування, гарячі клавіші, пробіли)
scripts/install.sh            # зібрати, встановити в /Applications і перезапустити
scripts/package.sh            # зібрати інсталяційний архів dist/Klavko-<версія>.zip
scripts/klavko-type.sh …      # імітація набору — див. розділ 3
```

Програма підписана сертифікатом Apple Development власника Mac; дозвіл «Універсальний доступ» (Accessibility) уже надано.
Якщо іконки Klavko немає в рядку меню: `open /Applications/Klavko.app`.

## 2. Підготовка

1. **Збережіть налаштування користувача** перед будь-якими змінами і відновіть їх після тестів:
   ```bash
   defaults export app.klavko.Klavko ~/Desktop/klavko-settings-backup.plist
   # після тестів:
   defaults import app.klavko.Klavko ~/Desktop/klavko-settings-backup.plist && scripts/install.sh
   ```
2. **Розкладки:** у системі ввімкнені `ABC` (англійська) і `Ukrainian-PC`. Klavko працює лише з парою uk/en.
3. **Місце для тестів:** TextEdit, новий документ у режимі простого тексту (Format → Make Plain Text, ⇧⌘T),
   щоб вимкнути власне автовиправлення macOS. Перед кожним випадком очищайте документ: ⌘A, потім Backspace
   (⌘ скидає те, що Klavko пам'ятає, — так і має бути).
   Не тестуйте в Terminal та iTerm2: вони за замовчуванням виключені.
4. **Гарячі клавіші за замовчуванням** (змінюються в налаштуваннях: клік по прапору в рядку меню → «Налаштування…»):

   | Дія | Клавіша |
   |---|---|
   | Змінити розкладку слова | ⇧⇧ (двічі Shift) |
   | Змінити розкладку виділеного або набраного | ⌥⌥ (двічі Option) |
   | Скасувати або повернути виправлення | не задано — призначте для тестів U1–U3 (далі в прикладах ⌃., `combo control 47`) |
   | Перекласти виділене | ⌘⌘ (двічі Command) |
   | Голосовий ввід | fn |
   | Backspace одразу після виправлення скасовує його | увімкнено |

   У прикладах нижче «виділене або набране» — це `tap option,command`; якщо залишаєте стандартну ⌥⌥, пишіть `double option`.

## 3. Як імітувати набір

**Важливо:** Klavko розпізнає натискання фізичних клавіш. Інструменти, що «вставляють» готовий текст
(Unicode-введення, вставка з буфера, AppleScript `keystroke` для символів поза розкладкою), не підходять:
результат буде неправильним, і це не помилка програми.

Використовуйте `scripts/klavko-type.sh` — він натискає ті самі клавіші, що й людина. Процес, з якого ви його запускаєте
(Terminal / ваш агент), має мати дозвіл Accessibility, інакше натискання не дійдуть. Натискання йдуть у програму на передньому плані:
спершу активуйте TextEdit (`open -a TextEdit` або клік у вікно), потім запускайте команду.

```bash
scripts/klavko-type.sh layout en             # увімкнути англійську розкладку (uk — українську)
scripts/klavko-type.sh current               # яка розкладка зараз
scripts/klavko-type.sh keys en "ghbdsn "     # натиснути клавіші, які в англ. розкладці дають "ghbdsn " (= "привіт" на укр.)
scripts/klavko-type.sh keys uk "дкую "       # натиснути клавіші, які в укр. розкладці дають "дкую "
scripts/klavko-type.sh tap option,command    # ⌥⌘ разом і відпустити
scripts/klavko-type.sh double shift          # ⇧⇧
scripts/klavko-type.sh combo control 47      # ⌃.  (47 — клавіша «.»)
scripts/klavko-type.sh key 51                # Backspace; 36 — Return; 123/124 — стрілки ←/→
```

`keys en|uk` лише вибирає, *які клавіші* натиснути; що з'явиться на екрані, вирішує розкладка, активна в цей момент.
Наприклад, «набрати слово в неправильній розкладці» = `layout en`, потім `keys en "ghbdsn "`.

Результат читайте з документа TextEdit (наприклад, `osascript -e 'tell application "TextEdit" to get text of document 1'`)
і за потреби робіть знімок екрана.

## 4. Що перевірити

Позначення: «EN» — перед випадком `layout en`, «UK» — `layout uk`. Пробіл у кінці рядка в `keys` — частина введення.

### 4.1. Автоматична зміна розкладки

| # | Дії | Очікується |
|---|---|---|
| A1 | EN, `keys en "ghbdsn "` | `привіт `, розкладка стала українською (уже на 3-й літері) |
| A2 | UK, `keys uk "руддщ "` | `hello `, розкладка — англійська |
| A3 | EN, `keys en "ghbdsn? "` | `привіт, ` («?» в англ. = «,» в укр.) |
| A4 | EN, `keys en "hello world "` | без змін |
| A5 | UK, `keys uk "привіт світ "` | без змін |
| A6 | Вимкнути «Перемикати вже під час набору» → EN, `keys en "ghbdsn "` | `привіт ` — перемкнулося лише після пробілу |
| A7 | Вимкнути «Автоматично виправляти розкладку» → EN, `keys en "ghbdsn "` | без змін |

| S4 | Новий документ, EN, `keys en "z "` | `z ` лишається (одна літера без контексту) |
| S5 | Новий документ, EN, `keys en "z ghbdsn "` | `я привіт ` — літера перемикається разом із наступним словом |
| S6 | Новий документ, EN, `keys en "S? pdbxfqyj "` | `І, звичайно ` |
| S7 | Новий документ, EN, `keys en "z hello "` | `z hello ` — наступне слово англійське, літера лишається |

| S12 | У TextEdit вже є текст `Привіт.` з попереднього сеансу: перезапустити Klavko (`scripts/install.sh`), клікнути в кінець тексту, EN, `keys en " Z levf. "` | `Привіт. Я думаю. ` — Klavko сам «бачить» текст перед курсором (через Accessibility) |
| S13 | Стерти Backspace більше символів, ніж набрано після перезапуску Klavko, потім EN, `keys en "Z levf. "` на початку порожнього рядка | `Я думаю. ` |
| S11 | Повторити A1, T1, S6 з `KLAVKO_TYPE_DELAY_MS=10` | ті самі результати, що й за звичайної швидкості |

## 5. Діагностика

Журнал подій (без набраного тексту — лише що сталося):

```bash
/usr/bin/log show --last 30m --style compact --predicate 'subsystem == "app.klavko.Klavko"'
```

Корисні записи: `Converted while typing`, `Auto-converted word`, `Corrected spelling`, `Switched a one-letter word`,
`Added a space after punctuation`, `Released N key(s) typed during a replacement`, `Hotkey: …`, `Undid … fix`, `Re-applied fix`, `Offering to add a reverted word to exceptions`,
`Slow event handling: N ms` (затримка обробки натискання; понад ~100 мс — варто повідомити).

## 6. Звіт

Для кожного випадку: номер, що введено, очікуване, фактичне (точний текст із TextEdit), «пройдено / ні».
Для непройдених додайте фрагмент журналу за той час і, якщо стосується інтерфейсу, знімок екрана.
Окремо вкажіть помічені затримки під час набору та будь-які хибні заміни правильних слів.
Наприкінці відновіть налаштування користувача (розділ 2, крок 1) і видаліть тестові винятки.
