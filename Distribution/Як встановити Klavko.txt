KLAVKO — перемикач розкладки й помічник для набору тексту на Mac
====================================================================

Klavko сам виправляє слова, набрані не в тій розкладці (ghbdsn → привіт),
виправляє очевидні помилки, ставить «лапки», тире й великі літери, має
голосовий ввід і переклад виділеного (українська ↔ англійська).
Програма безкоштовна й працює повністю на вашому Mac: набраний і
продиктований текст нікуди не надсилається.


ЩО ПОТРІБНО
-----------
• macOS 14 Sonoma або новіша.
• Mac з процесором Apple (M1, M2, M3, M4…). На Mac з Intel теж працює,
  але голосовий ввід там повільніший.
• Розкладки: англійська (ABC або U.S.) і українська (Ukrainian або
  Ukrainian – PC). Додати: System Settings → Keyboard → Input Sources → Edit.


ВСТАНОВЛЕННЯ
------------
1. Розпакуйте архів (двічі клацніть по ньому).

2. Перетягніть Klavko.app у папку «Програми» (Applications).
   Саме туди — тоді Klavko запускатиметься разом із Mac.

3. Перший запуск. Програма не з App Store, тому macOS спершу попередить,
   що не може перевірити розробника. Це очікувано.
   • Клацніть по Klavko.app правою кнопкою миші → «Відкрити» → «Відкрити».
   • Якщо такої кнопки немає (macOS 15 і новіші): спробуйте відкрити
     програму, закрийте попередження, потім відкрийте
     System Settings → Privacy & Security, прокрутіть униз і біля рядка
     про Klavko натисніть «Open Anyway» («Усе одно відкрити»),
     введіть пароль і знову відкрийте Klavko.

4. Дозвольте доступ до клавіатури. Klavko попросить «Універсальний доступ»:
   System Settings → Privacy & Security → Accessibility → увімкніть Klavko.
   Без цього дозволу програма не бачить, що ви набираєте.

5. Готово. У рядку меню вгорі з'явиться прапор поточної розкладки 🇺🇦 / 🇺🇸.
   Якщо замість прапора значок клавіатури зі знаком оклику — дозволу з
   кроку 4 ще немає.


ЯК КОРИСТУВАТИСЯ
----------------
• Просто друкуйте. Набрали слово не в тій розкладці — Klavko виправить
  його й перемкне розкладку.
• Налаштування: клацніть по прапору в рядку меню → «Налаштування…».

Гарячі клавіші (змінюються в налаштуваннях):
• ⇧ ⇧ (двічі Shift) — змінити розкладку слова.
• ⌥ ⌥ (двічі Option) — змінити розкладку виділеного тексту або всього,
  що ви щойно набрали.
• ⌘ ⌘ (двічі Command) — перекласти виділений текст (укр. ↔ англ.).
• fn (🌐) — голосовий ввід: натисніть, говоріть, натисніть ще раз —
  текст з'явиться там, де курсор. Esc — скасувати.

Голосовий ввід:
• Під час першого запису macOS попросить доступ до мікрофона й до
  розпізнавання мовлення — дозвольте.
• Щоб клавіша fn (🌐) не робила нічого іншого:
  System Settings → Keyboard → «Press 🌐 key to» → «Do Nothing».
• Для значно кращої якості (розділові знаки, автоматичне визначення мови):
  Налаштування → «Голосовий ввід» → «Завантажити (~600 МБ)».
  Це модель NVIDIA Parakeet; завантажується один раз, далі працює без
  інтернету. Без неї працює вбудоване розпізнавання macOS.

Переклад:
• Виділіть текст будь-де і двічі натисніть ⌘. Напрямок (українська →
  англійська чи навпаки) визначається сам; кнопка з прапорцями в панельці
  перекладає в інший бік. Return — замінити виділене, ⌘C — скопіювати,
  Esc — закрити.
• Перекладає вбудований перекладач macOS прямо на вашому Mac (потрібна
  macOS 15 або новіша). Першого разу macOS запропонує завантажити мови —
  погодьтеся.

ЯКЩО ЩОСЬ НЕ ПРАЦЮЄ
-------------------
• Нічого не виправляється: перевірте дозвіл з кроку 4 і що в системі є
  обидві розкладки (англійська й українська).
• У якійсь програмі Klavko заважає: клацніть по прапору → «Не виправляти
  в «назва програми»».
• Значок замка замість прапора: інша програма зараз має захищене введення
  (наприклад, поле пароля) — це тимчасово.


ВИДАЛЕННЯ
---------
Клацніть по прапору → «Вийти з Klavko», потім перетягніть Klavko.app з
«Програм» у кошик. Голосова модель (якщо завантажували) лежить у
~/Library/Application Support/FluidAudio/Models/parakeet-ultra — її теж
можна видалити.
