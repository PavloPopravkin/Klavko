# Klavko

Безкоштовна програма для macOS, яка виправляє слова, набрані в неправильній розкладці (українська ↔ англійська), очевидні помилки та оформлення тексту, а ще має голосовий ввід. Працює повністю на Mac, без інтернет-сервісів і ключів.

## Завантажити

**[⬇︎ Остання версія (Klavko-….zip)](../../releases/latest)** — розпакуйте й дотримуйтеся інструкції «Як встановити Klavko.txt» з архіву.

Потрібно: macOS 14 або новіша, розкладки англійська та українська. Програма не нотаризована Apple, тому під час першого запуску macOS попередить — в інструкції описано, як відкрити.

## Як працює

- Набираєте `ghb…` — Klavko вже на третій літері бачить, що англійських слів так не починається, а українських («при…») багато, і перемикає розкладку посеред слова.
- Слово, яке не розпізналося під час набору, перевіряється після пробілу, Tab, Enter або розділового знака: `ghbdsn?` стане `привіт,`.
- **Помилки** виправляються після слова, якщо вони очевидні: `пртвіт` → `привіт`, `рлбиш` → `робиш` (сусідня клавіша), `ПРивіт` → `Привіт` (залиплий Shift). Сумнівні випадки (`helo` — help чи hello?), імена посеред речення та слова з цифрами залишаються як є. Вмикається в налаштуваннях і в меню; має власний звук.
- Забутий пробіл після розділового знака додається: `Привіт,як` → `Привіт, як` (після крапки — лише перед великою літерою; числа, адреси, дефіс, дужки й лапки не змінюються).
- **Оформлення тексту** (кожне вмикається окремо): велика літера на початку речення; `...` → `…`, `"` → `«»` / `“”`, ` - ` → ` — `, `(c)` → `©`; продовження списків `- ` і `1. ` після Enter; власні заміни (`сп` → `спасибі`, `:)` → `🙂`).
- **Зміна регістру** гарячою клавішею: малі → Перша велика → ВЕЛИКІ — для поточного слова або виділеного тексту.
- **Голосовий ввід** (клавіша fn / 🌐): говоріть українською чи англійською, повторне натискання вставляє текст у місце курсора, Esc скасовує. Розпізнає модель NVIDIA Parakeet Ultra (через FluidAudio) на цьому Mac — з розділовими знаками й визначенням мови; модель (~600 МБ) завантажується один раз. Російський результат ніколи не вставляється. Поки модель не завантажена — вбудоване розпізнавання macOS.
- Слова з великих літер (NATO, ЗСУ) не змінюються — це вимикається в налаштуваннях.
- **Винятки** — слова, які Klavko ніколи не змінює. Якщо двічі скасувати заміну того самого слова, Klavko запропонує додати його до винятків.
- Іконка в рядку меню показує прапор поточної розкладки 🇺🇦 / 🇺🇸. Після перемикання лунає тихий звук (можна змінити або вимкнути).
- **Backspace** одразу після заміни — скасувати (можна вимкнути). Це слово більше не змінюватиметься до перезапуску програми.
- У терміналах (Terminal, iTerm2) програма за замовчуванням вимкнена. Будь-яку програму можна виключити через меню.
- Набрані символи нікуди не записуються: у пам'яті зберігається лише текст від останнього кліку чи Enter.

Гарячі клавіші (змінюються в «Налаштування…»):

| Дія | За замовчуванням |
|---|---|
| Змінити розкладку слова | ⇧⇧ (двічі Shift) |
| Змінити розкладку виділеного, а якщо нічого не виділено — всього набраного (від кліку, Enter чи стрілок) | ⌥⌥ (двічі Option) |
| Скасувати останнє виправлення (повторне натискання повертає його) | не задано |

Гарячою клавішею може бути клавіша з модифікаторами (⌃⇧Space), самі модифікатори разом (⌥⌘) або подвійне натискання (⇧⇧, двічі ⌥⌘).

Повторне натискання тієї самої клавіші одразу після заміни скасовує її.

## Як виправляються помилки

Усе локально, на словниках macOS; текст нікуди не надсилається.

1. Слово, якого немає в словнику, отримує кандидатів: усі словникові слова на відстані однієї правки (вставити пропущену літеру, прибрати зайву, переставити дві, замінити сусідньою клавішею) плюс підказки macOS для цього слова в реченні.
2. Кожен кандидат отримує оцінку: «ціна промаху» (пропущена літера — найдешевша, далека клавіша — найдорожча) мінус частотність слова мінус підтримка контекстом речення.
3. Заміна відбувається лише тоді, коли переможець близький, поширений або підтриманий контекстом і помітно кращий за другого (для слів до 4 літер — ще помітніше). Інакше слово лишається як є.

Не змінюються: правильні слова, слова з великої літери посеред речення, абревіатури, слова з цифрами чи змішаними розкладками, адреси й код (`user@mail`, `http://…`, `file_name`), слово, у яке користувач повернувся Backspace, винятки та програми зі списку.

## Діагностика

Журнал без вмісту набраного тексту:

```bash
/usr/bin/log show --last 1h --predicate 'subsystem == "app.klavko.Klavko"'
```

Потрібні розкладки ABC (або U.S.) і Ukrainian / Ukrainian-PC.

## Збірка

```bash
swift test               # тести логіки
scripts/install.sh       # зібрати, встановити в /Applications і запустити
```

Встановлена копія (`/Applications/Klavko.app`) запускається під час входу в систему. Для швидкої перевірки без встановлення: `scripts/build-app.sh && open build/Klavko.app`.

Під час першого запуску дозвольте доступ у **System Settings → Privacy & Security → Accessibility**.

## Структура

- `Sources/KlavkoCore` — розкладки, правила визначення мови, перевірка орфографії (без дозволів, покрито тестами).
- `Sources/Klavko` — програма в рядку меню: перехоплення клавіш, заміна тексту, меню.
